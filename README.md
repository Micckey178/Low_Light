# ATHER — Classical Low-Light Image Enhancement

ATHER is a desktop application for classical, non-AI low-light image enhancement.

## Main capabilities
- Load images and capture images using a camera.
- Apply classical enhancement algorithms.
- Compare original and enhanced images.
- View image quality measurements.
- Explore the Processing Journey.
- Use rule-based Adaptive Component Processing (ACP) recommendations.
- Run algorithm benchmarks.
- Generate a PDF performance evaluation report.

## Algorithms
- Gamma Correction
- Contrast Stretching
- Histogram Equalization
- CLAHE
- Adaptive Gamma
- Single-Scale Retinex (SSR)
- Multi-Scale Retinex (MSR)
- LIME
- Homomorphic Filtering

## Technology
Python, OpenCV, NumPy, Pillow, Matplotlib, PySide6 and ReportLab.

ATHER uses classical image-processing techniques. It does not require neural networks or pretrained AI models.

The packaged Windows executable and its user documentation are distributed separately from the source repository.
